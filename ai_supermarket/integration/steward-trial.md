# 用个人总管试用AI超市

v0.117，2026-09-23。本项目原创。当前源码候选包含完整个人总管和超市客户端，不必从开发目录另拷模块。需已有Python 3.12及Tk；本机双端服务还需包内requirements-http.txt所列依赖。源码包不含Python、第三方依赖、模型账号或真实商品。

## 先检查与打开界面

在解压后的源码根目录执行。`work/my-steward`是本次新建的私有总管数据目录，不指向已有个人账号设置：

```powershell
python -X utf8 -B -m steward.desktop --check
python -X utf8 -B -m steward.desktop --data work/my-steward
```

检查不会联网或运行模型。codex_found只表示找到程序，不能证明账号可用。打开界面也不会自动运行模型；新档案默认不允许模型读取任务上下文，由使用者在已有账户授权范围内配置。关闭界面不会停止另两个终端中的市场与供应商。

## 准备免费资源连接

按[分目录双端演练](provider-pair.md)在全新目录prepare、check、启动市场和供应商。本次如果使用总管，就不先执行另一条exercise脚本路径。prepare自动生成`steward-connection.json`，固定原免费任务、零元商品预算、结果目录和24次网络尝试；只包含凭据路径，不包含凭据内容。

1. 将生成的`market/goal.md`目标交给总管。待其展示目标和验收草案后，核对内容并点击“确认并连接超市”。这一步确认目标并打开连接窗口，尚不启动执行。样例查询虚构库存，输出达到10件库存的补货数量、依据和未知项。
2. 点击“导入配置”，选择`steward-connection.json`→“检查配置”→“保存并启用”。不需要手填八个连接字段。已有确认目标的空闲任务，按钮显示“超市连接”。如果输入框仍有修改意见，请先发送并等待新草案，不能确认旧目标。
3. 关闭连接窗口，点击“继续任务”，在使用者已授权的模型范围内启动。执行前自动初查；AI选择资源、调用API并读取核验结果，继续制作实际成果。零元资源不代表模型免费，网络次数也不是模型费用上限。直接关闭未保存的连接窗口会保留已确认目标、保持空闲；可再次打开配置，不会自动运行。
4. 检查实际成果中库存、计算、许可和未知事项。样例库存7件，目标10件，因此应补货3件；不得编造价格或到货时间。模型说完成不能替代成果检查。

详细字段、停用和恢复见[总管连接说明](../../docs/ai-supermarket-steward-remote.md)。重启总管仍使用同一个`--data`目录；目标改变需核对新的任务范围，不能复用旧绑定。出现身份撤销、超时或结果未知时，保留原记录按原请求恢复，不重建目录绕过次数。服务停止后连接检查仍可能通过，但执行时不能交付资源。

## 已有真实市场的接入者

不必创建固定样例。请市场管理员提供本任务已获准的连接JSON与私有凭据文件，按照上述界面导入。允许用途、收费条件和预算以真实授权为准。收费模式需要可信宿主接续钱包；当前界面没有付款执行器，不能把导入成功当作支付接通。

本机已验证独立解压后的导入、界面启动，以及真实需求界面、后台线程、连接保存和HTTP取用到成果的完整链路；仅模型替换为原创脚本。尚未验证另一台设备兼容、真实模型的选货效果、真实供应商及支付。此包为内部源码候选，没有公开发布或更改源码许可；私有试用目录、凭据和数据不能随包发送。
