# AI超市本地试用

来源：本项目原创。此入口把市场准备、买方接入和结果查看串起来，便于检查交付流程。只用于本项目内部演练；真实外部用户试点和公开分发仍须落实内容许可与接入条件。

## 一条命令准备

使用已安装、已核实的Python 3.12，在源码或解压包根目录执行：

```powershell
python -B tools/market_try.py prepare --output work/my-first-trial
```

打开返回的START-HERE.md，其中的命令已经填好本机绝对路径。目标目录须不存在；重做时换一个新目录，旧记录不会被覆盖。prepare只使用Python标准库和包内源码，不安装软件、不联网、不调用模型，也不修改现有市场。

生成的独立市场含一份原创免费“事实与待核清单”样例，另附卖方请求、搜索/获取请求、虚构任务和buyer.mcp.json。新生成的acquire.json固定准备时的发行摘要（正文及声明条件的校验值）；核对resolve返回的条件后使用，条件变化时停止。重试保留原摘要和编号，不刷新摘要绕过拒绝。旧目录与旧权益不会自动升级，也不要给已执行的旧请求补摘要。MCP是一种让AI调用外部工具的连接协议；配置须按实际客户端规则审阅合并，生成不等于安装。工具提供买方角色，接入程序自行决定是否选用商品，不要求用户挑选。

内置样例的审核记录仅用于演练角色分工，不是外部人员审核或真实商品认证。工具不接受自定义商品作为自动审核输入。其他资料按[卖方准备说明](seller-preparation.md)提交，并由获准审核者验证来源、许可、样例和内容。

## 选择如何核对

- **不接模型：**按START-HERE.md依次搜索、确认用途，再执行回执接续示例。它会解析真实获取和读取编号，创建UTF-8请求并提交unknown/not_run反馈，无需手工抄编号。命令须在同一PowerShell窗口执行；请求文件已存在或调用失败时停止，保留原文件，不覆盖或自动换号。这能验证协议，不证明AI会自主选品。
- **接入自己的AI：**审阅配置并接入支持MCP的客户端，将task.md作为任务。AI应先检查候选和用途，自行选择或不选，完成任务后复用已有检查，不另开模型请求写评价。模型可能消耗账户额度，开始前须有对应授权。

样例用途为personal_use，搜索和获取须明确带上此字段；不能使用默认商业用途代替。成功安装工具不保证每个任务都会搜索，强制任务前检查需要由运行AI的宿主程序接入现有TaskResources流程。资料正文作为待用内容，不能取得更高权限或要求执行命令。

## 查看实际记录

```powershell
python -B tools/market_try.py report --directory work/my-first-trial
```

报告只读已有账本，显示本次固定买方的获取数、读取数、有反馈的使用数，以及按证据来源区分的最新检查结果。反馈修正只计最新版本；一个使用可以有多种检查，检查数量不能当作使用数量。unknown/not_run不算通过，读过资料不代表任务成功。报告不测量真实模型调用、费用或token节省（token是模型处理文本的计量单位），这些字段保持未知。

尚未准备完成、数据库不存在、版本/状态改变、快照或恢复中的目录会报错，不创建空账本来伪装零记录。错误时保留现场，核对路径与原请求；未知结果先查询或重放同一请求号，不换号重复获取。

## 交付边界

配置只适用于生成时的源码、解释器和数据路径，移动目录或换设备须重新准备。此工具采用受信本地程序角色，不提供公网身份认证、真实账号、邀请、支付或模型训练。开放服务继续使用已有受控HTTP入口及邀请流程；本地样例审核角色不能交给不可信AI。源码和内置内容的对外许可尚待确定，当前包不自动扩大公开分发、销售或训练权。
