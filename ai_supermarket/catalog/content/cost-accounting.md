# 任务成本核算方法

分开记录模型用量、货币支出和人员时间；字节数不能代替token。
任务总量包括输入、输出、可观测推理、缓存输入、工具、检索、重试、失败、反馈和抽检分摊。
总成本 = 可核对的各项费用 + 人工成本 + 失败补救。
每合格任务成本 = 全部尝试总成本 / 合格任务数；合格数为0时返回不可计算。
按模型和版本区分计量。拿不到用量写缺失，不按0估算。
情景估计列低/基准/高输入与公式，不能标成真实收益。

检查：费用来源、币种、税费、时间窗口一致；通过质量门槛后才报告节约。
